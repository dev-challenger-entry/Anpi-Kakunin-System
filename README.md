**概要**  
本プロジェクトでは、Webアプリ開発の手順をあとから復習できるように、  
こまめにコミットをおこないます。  
学習目的でGitを活用するため、なるべく、『エラーが起きた場合もどんな問題が起きてどんなエラーを解決できたのか』という記録を残しつつ進めていきます。

**本学習を通して作るもの**  
緊急事態において「迷わず、素早く、確実に」安否報告・集計を行うための企業向け安否確認システムです。  

**設計思想**  
１．災害時のアクセス集中を考慮し、必要以上に複雑化させず、データベース構造もシンプルな構成を意識します。  
２．安否確認アプリにおいて、余計な装飾は不要。シンプルを突き詰めて、説明書が不要なデザインを目指します。  
３．「何を追加するか」だけでなく、「何を削るべきか」も意識し、必要な機能に絞った設計を行います。

**開発動機**  
「多機能だから良い」のではなく、「必要なときに迷わず使える」ことに価値がある。
そう考え、必要最小限の機能でありながら、実際の利用者に必要とされるWebアプリケーションを作る経験を得るため、本システムを開発しました。

題材として選んだのは、災害時の安否確認です。

災害時には、利用者が平常時のように落ち着いて操作できるとは限りません。  
だからこそ、機能を増やすのではなく、何を残し、何を削るかを考えることが重要です。  
「迷わず、素早く、確実に」安否を報告・集計できることを軸に、シンプルさと堅牢性を意識して開発しています。
