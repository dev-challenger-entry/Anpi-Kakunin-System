Spring Boot × React 学習リポジトリ



Webアプリ開発の手順をあとから復習できるように残しておくリポジトリです。



バックエンドは Spring Boot、フロントエンドは React を使用し、ローカル環境で動作確認しながら開発を進めます。



**開発環境**

開発ツール：Eclipse（Pleiades日本語版）

Java：21

Spring Boot：4.1.0

ビルドツール：Gradle（Groovy）

OS：Windows 11



**初期設定で選択した依存関係**



|ライブラリ|役割|
|-|-|
|Spring Web (spring-boot-starter-web)|ブラウザからのアクセスを受け付け、Webアプリを動かすための基本機能|
|Thymeleaf (spring-boot-starter-thymeleaf)|Javaのデータを画面（HTML）に表示させる仕組み|

さらに開発効率あげたい人は以下の手順で

１．node -vとコマンドプロンプトで確認　Node.jsの確認

２．npx -vとコマンドプロンプトで確認　Reactのツールを呼び出すために必要な機能

３．コマンドプロンプトで、.git があるプロジェクトルートに移動し、以下のコマンドを実行する

　　　npm create vite@latest my-react-app -- --template react

４．すでに作ってあったJavaの「Spring Boot」というフレームワークで書かれたバックエンド（サーバー側）のプログラムへ、@CrossOrigin(origins = "http://localhost:5173")を書き足す。

　それによってブラウザのCORS制限を回避して、異なるポート同士(5173と8080)の通信を許可する。



こうすると、コードを書き換えたあと、保存して、ブラウザ側で再読み込みしたら変更が反映される。
