バックエンドはJavaのSpringboot Project
フロントエンドはreact

これらを用いて、ウェブサイトを制作していくものとする

ローカル環境で動作確認しながら日々、開発していくための手順はつまづきやすい
そのため、別のテキストファイルへメモしておくこととした

.............................................................................



１　最初は、バックエンドのローカルホストを動かす
　　　@SpringBootApplicationとpublic static void main(String[] args)と記載されているJava拡張子ファイルがそのメインスイッチ
　　→バックエンドが動き始めました！


２．次は、フロントエンドを動かす
　　エクスプローラーで my-react-app フォルダーの中に入る→エクスプローラー上部でフォルダのアドレスをコピー
　→次にターミナルを開く→cd　先ほどコピーしたフォルダのアドレスを貼り付け
　→npm run dev
　→フロントエンドも動き始めました！
