　以下の手順でフロントエンドで React を利用を始めて開始することができる
　開発初期のやり方

１．node -vとコマンドプロンプトで確認　Node.jsの確認

２．npx -vとコマンドプロンプトで確認　Reactのツールを呼び出すために必要な機能

３．コマンドプロンプトで、.git があるプロジェクトルートに移動し、以下のコマンドを実行する

　　　npm create vite@latest my-react-app -- --template react

ただし、このコマンドは最初の１回だけする。
以後の開発では使用しない。
　　　npm run dev
開発中はこちらを使うこと。

１　最初は、バックエンドのローカルホストを動かす
　　　@SpringBootApplicationとpublic static void main(String[] args)と記載されているJava拡張子ファイルがそのメインスイッチ
　　→バックエンドが動き始めました！


２．次は、フロントエンドを動かす
　　エクスプローラーで my-react-app フォルダーの中に入る→エクスプローラー上部でフォルダのアドレスをコピー
　→次にターミナルを開く→cd　先ほどコピーしたフォルダのアドレスを貼り付け
　→npm run dev
　→フロントエンドも動き始めました！
